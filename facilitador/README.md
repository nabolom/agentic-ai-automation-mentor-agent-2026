# Kit del facilitador

Este kit acompaña las sesiones técnicas de la cohorte. La primera combina S1+S2: **Panorama de Agent Engineering Q4-2026 y primera medición**. No reemplaza las guías del curso: te ayuda a **facilitar la experiencia**, detectar atascos y mantener el foco en evidencia.

## La historia que debes sostener

```text
Primero acoto.
Luego decido qué delegar.
Después mido.
Diagnostico la falla.
Pongo límites.
Dejo un sistema que otra persona puede operar.
```

## Principios de facilitación

- **No empieces por la herramienta.** Empieza por la decisión y el contrato.
- **No arregles el sistema por el Aprendedor(a).** Pide evidencia y deja que el Aprendedor(a) fije la salida esperada.
- **Un solo proceso.** Si aparecen dos, pide elegir uno.
- **Seis casos bastan para avanzar.** Diez son extensión.
- **“No necesito loop” es una buena respuesta** cuando hay verificación externa y evidencia.
- **El camino dorado es un andamio, no un juguete aislado.** Úsalo para transferir criterio.
- **Los fallos son material de clase.** No los tapes antes de que el grupo pueda leerlos.
- **Si falla la herramienta, rescata el aprendizaje, no la integración.**
